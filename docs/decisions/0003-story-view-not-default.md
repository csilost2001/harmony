# 0003 「流れ」は既定の表示にしない

**状況**: 処理フローの「流れ」表示 (入れ子と言葉の条件で読む) を、開いたときの既定にするか。

**決めたこと**: 既定はカード表示のまま。「流れ」は切り替えて使う。

**理由**: カードは、工程を 1 つずつ組み立てる作業に向き、利用者の慣れもある。「流れ」は読む・細かい仕様を書くための表示で、作業の種類が違う。既定を変える根拠 (利用実績) がまだ無い。

**選ばなかった案**: 「流れ」を既定にする / 工程の数で自動的に切り替える (予測しにくい)。

**結果**: [process-flow-story-view.md](../spec/process-flow-story-view.md)。利用の様子が分かれば見直す (見直すときは、新しい記録で置き換える)。
