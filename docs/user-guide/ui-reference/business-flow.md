# 業務フロー (スイムレーン)

> **ルート**: 一覧 `/w/:wsId/business-flow/list`、編集 `/w/:wsId/business-flow/edit/:id`
> **仕様**: [business-flow.md](../../spec/business-flow.md)

## 概要

画面・処理フローより上の「業務の流れ」を、誰 (部門・役割・システム) が何をするかをレーンに分けて描く。工程から、実際の画面と処理フローへたどれる。図は設計データから自動で配置される (座標を持たない) ので、設計者は工程・レーン・つながりだけを編集する。

## 一覧

ヘッダーメニュー「業務フロー」。名前・ID で絞り込み、「業務フロー追加」で新規作成 (名前と ID を入力)、複製、削除ができる。新規作成の直後は編集を始めた状態で開く。

## 編集

| エリア | 内容 |
|---|---|
| 左 | レーンと工程の一覧。持ち手 (⋮⋮) のドラッグで並べ替え (行のクリックは選択) |
| 中央 | 図。工程をクリックで選択。「次の工程を追加」で同じレーンに新しい工程を作ってつなぐ |
| 右 | 選んだ工程の設定: 名前・種類 (開始 / 作業 / 判断 / 終了)・レーン・説明・実現する画面・処理フロー・次の工程 (判断では分岐の条件つき) |
| 図の下 | 要確認 (開始がない・到達できない工程・参照先がない 等) |

編集の始め方・保存・同時編集は [共通の操作](common-operations.md) を参照。

## 関連

- 設計書ビュー: 「業務フロー」の章に図と工程表が出る
- 画面・処理フローの ID を改名すると、工程の参照も追従する
