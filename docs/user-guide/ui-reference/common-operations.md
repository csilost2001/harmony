# 共通の操作

> どの画面にも共通する基本の操作。画面ごとの違いは各画面のページを参照。

## 開く・探す

| 操作 | 方法 |
|---|---|
| 画面・テーブル・処理フローなどへ飛ぶ | `Ctrl+K` (Mac は `⌘K`) またはヘッダーの虫眼鏡。ID・名前・物理名・URL で絞り込み、`Enter` で開く ([quick-open.md](../../spec/quick-open.md)) |
| 一覧・設定を開く | ヘッダー左のメニュー。開いた画面はタブになる (一覧は 1 つだけ、個別の編集はリソースごと) |

| 新しく作る | `Ctrl+K` で「新規 テーブル」のように入力して `Enter`。一覧を開いて追加ダイアログを出す |
| ショートカットの一覧を見る | `?` キー (入力欄の外で) またはヘッダーのキーボードの印。一覧・エディタ・画面デザイナで使えるキーが載っている |

## 編集する (編集開始 → 保存)

設計書は、**開いただけでは書き換わらない**。

1. 画面を開くと「閲覧中」。値は読めるが入力はできない (入力例の薄い文字も閲覧中は出さない)
2. 「**編集開始**」を押すと「編集中」になる。ここから先の変更はサーバ側の下書きに保たれ、ブラウザを閉じても、次に開いたときに「再開 / 破棄」を選べる
   - 一覧から「作成して編集」「作成」した直後 (テーブル・処理フロー・業務フロー・帳票など) は、編集を始めた状態で開く
3. 変更したら、上の「編集中」の帯の「**保存**」(`Ctrl+S`)。変更がないあいだは押せない (保存の入口は、この帯の 1 か所だけ。見出し右には「リセット」だけが残る)。入力欄にカーソルがあっても `Ctrl+S` で保存できる (ブラウザの「名前を付けて保存」は出ない)。保存しても編集中のまま
   - 変更があるあいだは、「保存」の隣に「**変更点**」が出る。押すと、読み込んだ (最後に保存した) 内容から何が変わったかを、追加 / 変更 / 削除 / 順序の一覧で確かめられる (読むだけで、保存はしない。`Esc` で閉じる)。行は id で対応づけるので、行の挿入でほかの行が「変更」に見えることはない
4. やめるときは「**破棄**」(編集セッションを終えて元の内容に戻る)。「リセット」は編集中のまま、最後に保存した内容へ戻す。`Ctrl+Z` / `Ctrl+Y` で 1 つずつ取り消し / やり直し

### 保存の通知・未保存の警告

- 保存すると、画面の下に「保存しました」が数秒出る。操作が失敗したときは、赤い通知で理由が出る (接続が切れているときは、その旨のダイアログ)
- ブラウザのタブ名には、開いている設計の名前が出る (未保存の変更があれば先頭に「●」)。未保存の変更があるまま、ブラウザを閉じたり再読み込みしようとすると、確認が出る

### タブの「●」

タブ名の横の「●」は、**保存していない変更がある**ことを表す。編集を始めただけでは付かず、変更すると付き、保存・リセット・破棄で消える。

## 新しく作る (ID の入力)

画面・テーブル・処理フロー・業務フロー・帳票などの新規作成ダイアログには「ID (kebab-case)」欄がある。ID はファイル名・URL・他の設計からの参照に使われる。

- 名前 (テーブル・シーケンス・DB ビューは物理名) が英数字なら、ID は**自動で入る**。自分で書き換えると、以後は自動で変わらない
- 日本語だけの名前では ID を作れない。英語で入力するか、「**仮の ID を付ける**」を押す (あとから「ID 変更」で直せる)。AI が接続されていれば「AI 提案」も使える
- 既にある ID と重なると、連番を付けた候補を「適用」で入れられる

## 同時に編集する (共同編集)

同じ設計書を別の人・AI が編集していても、閲覧はできる。

- ヘッダー右の編集セッションの印に、「他 N 件が編集中」と出る (開く前に分かる)。開くと、誰が編集中か (名前が付いていない参加者は「ゲスト (xxxx)」)、最終操作の時刻、閲覧人数が並ぶ
- 「閲覧」で見る側に参加、「引き継ぐ」で編集権を譲り受ける (いまの編集者は閲覧に変わる)、「破棄」で下書きを捨てる
- 別の人が先に保存していた場合は、保存時に「上書きして保存」か「キャンセル」を選ぶ
- 自分の名前は、ヘッダー右の「ゲスト」(名前の表示) を押して設定する。設定すると、ほかの人から「<名前> が編集中」「閲覧中: <名前>」と見える (未設定なら「ゲスト (英数 4 文字)」)。このブラウザにだけ保存され、末尾の `@AI` は名乗れない
- 他の人が編集中のときは、画面上部に「<名前> が編集中」と出る。解除する場合は「強制解除」で、その下書きを引き継ぐか破棄するかを選ぶ

詳細: [edit-session-protocol.md](../../spec/edit-session-protocol.md)

## 参照元を調べる

各エディタのヘッダー右の「参照元」で、いま開いている設計 (画面・テーブル・処理フロー等) を**参照している設計**が種類ごとに並ぶ。名前をクリックすると、その設計を開く。ID を変更する前や、削除する前の確認に使う。閲覧中でも使える。AI からは MCP の `designer__find_references`。仕様: [references.md](../../spec/references.md)

## 並べ替え

一覧の持ち手 (⋮⋮) をドラッグ。キーボードでは持ち手にフォーカスして `Space` で持ち上げ、`↑` `↓` で動かし、`Space` で置く (`Esc` で取り消し)。

## 設計の要確認

設計の抜け・矛盾 (参照先がない、必須の定義がない等) は、保存を妨げず「要確認」として表示される。ダッシュボードの「設計の要確認」パネル、設計書ビュー、`npm run check:design -- <workspace>` で一覧できる。

## サーバとの接続

画面を使っている途中で backend サーバとの接続が切れると、ヘッダー中央に赤い帯「サーバとの接続が切れています — 再接続しています」が出る。切れている間は保存・読み込みができない。自動で再接続し、復旧すると緑の帯「接続が復旧しました」が数秒出て消える。編集中の内容は画面に残っているので、復旧してから保存する。最初から接続できないときは、全画面のエラー表示 (起動方法つき) になる。
