# 帳票

> **ルート**: 一覧 `/w/:wsId/report/list`、編集 `/w/:wsId/report/edit/:id`
> **仕様**: [report.md](../../spec/report.md)

## 概要

納品書・一覧表などの出力帳票を、部 (ヘッダー・明細・フッターなど) と項目に分けて設計する。出力契機・出力条件・データの出どころ (テーブルの列) を決め、用紙の見本図を見ながら組み立てる。

## 一覧

ヘッダーメニュー「帳票」。新規作成 (名前と ID)・複製・削除。新規作成の直後は編集を始めた状態で開く。

## 編集

| エリア | 内容 |
|---|---|
| 左 | 基本設定 (名前・出力・契機・出力条件) と部の一覧。持ち手 (⋮⋮) のドラッグで部を並べ替え。部の追加 (種類を選ぶ)・削除 |
| 中央 | 用紙の見本図。項目をドラッグして同じ部の中で並べ替えられる (落とす位置は青い線で示す) |
| 右 | 選んだ部・項目の設定。項目は種類・見出し・データの出どころ (テーブル / 列)・書式・揃え・幅 |
| 見本図の下 | 要確認 (参照先のテーブル・列がない、など) |

編集の始め方・保存・同時編集は [共通の操作](common-operations.md) を参照。

## 関連

- 設計書ビュー: 「帳票」の章に見本図と項目表が出る
