設計書ビュー

ルート: /w/:wsId/document 仕様: design-document.md / test-viewpoints.md

概要

設計データ (JSON) から、日本の現場で使われる設計書の体裁 (表紙・一覧・項目定義表・処理記述表・CRUD 図・業務フロー・帳票・要確認事項・テスト観点) を作って読めるようにする。読み取り専用で、ここで直しても原本には戻らない。修正は各画面で行う。

操作

操作内容
目次左の目次から章へ移動
再生成原本の最新から作り直す
別タブで開く印刷用の単独ページとして開く
HTML で保存目次・スタイル込みの 1 ファイルとして保存 (そのまま配布・印刷できる)
要確認 N 件設計の抜け・矛盾の一覧へ

紙面は、アプリのテーマ (ライト / ダーク) に関係なく明色で表示する (印刷・PDF 化のため)。

コマンドラインから

目的コマンド
設計書 HTML を書き出すnpm run export:doc -- examples/<project-id> --out .tmp/doc.html
要確認事項を検査するnpm run check:design -- examples/<project-id> [--strict]
テスト観点表を書き出すnpm run export:tests -- examples/<project-id> --format csv
