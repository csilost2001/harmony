# 表の入力: キーボード操作

表計算ソフトのように、マウスを持たずに行・列へ次々と入力するための操作。原本 (JSON) とスキーマは変えない。

## 行ごとに入力欄が並ぶ表 (画面項目・規約カタログ・ビュー定義のカラム・処理フローの入出力) — `useGridKeyboard`

| キー | 動作 |
|---|---|
| Enter | 1 つ下の行の同じ列へ。最後の行で、その欄に値が入っていれば行を追加し、新しい行の項目 ID 欄へ (行の追加は画面項目だけ。ほかの表は何もしない) |
| Shift+Enter | 1 つ上の行の同じ列へ |
| ↑ / ↓ | 文字を打つ欄 (テキスト) から、上下の行の同じ列へ。数値・選択・候補が開いている欄では通常の動作 |
| Esc | 欄から出る |

- 列は `<td>` の位置で数える。欄のない行 (詳細の展開行など) は飛ばす。
- 入力欄の部品 (候補の補完など) が自分で処理したキーと、日本語入力の変換中の Enter には反応しない。
- 実装: `frontend/src/hooks/useGridKeyboard.ts`。表のルートに `onKeyDown` を付けるだけで使える。

## テーブルのカラム (一覧 + 編集パネル) — `useDetailPanelKeyboard`

カラムは一覧の行を選び、編集パネルで入力する。パネルを開く・次の行へ移るたびに、最初の入力欄へカーソルが入る。

| キー | 動作 |
|---|---|
| Enter | 次の欄へ。最後の欄なら次のカラムへ (最後のカラムなら新しいカラムを追加) |
| Ctrl+Enter / Ctrl+Shift+Enter | 次 / 前のカラムへ |
| Esc | 入力欄から出る (一覧の矢印キー操作へ戻る)。もう一度でパネルを閉じる |

- 閲覧中・ソート中は、新しいカラムの追加はしない (移動のみ)。
- 実装: `frontend/src/hooks/useDetailPanelKeyboard.ts`。ほかの「一覧 + 編集パネル」の画面にも使える。
