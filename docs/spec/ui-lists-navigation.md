# 一覧・探索・見通し — 仕様書 (UI 改善提案 続編 第 6 弾)

**Status**: 実装済 (2026-10、ISSUE #1516)
**関連**: [list-common.md](list-common.md) / [quick-open.md](quick-open.md) / [ui-keyboard.md](ui-keyboard.md) / [ui-direct-manipulation.md](ui-direct-manipulation.md)

探したいものにすぐ着く。いまどこにいるか、何が関係するかが分かる。**覚えるもの (保存した絞り込み・グループの選び方・開いた履歴・閉じたタブ・パネルの非表示) は、このブラウザにだけ置き**、設計の原本 (JSON) には書かない。スキーマは変えない。キー操作の一覧は「?」(`utils/shortcuts.ts`)。

## 1. タブの履歴・パンくず (#106〜#109)

| 操作 | 内容 | 実装 |
|---|---|---|
| 閉じたタブを開き直す (#106) | 閉じたタブを新しい順に 10 件覚え (ピン留めも)、**Ctrl+Alt+T** で直前のものを開き直す。Ctrl+Shift+T も同じだが、多くのブラウザが先に使うのでページへ届かないことがある。タブバー右端のボタンで一覧から選べる。コマンドパレットにも「閉じたタブを開き直す」。他を閉じる・右側を閉じるで消えたタブも覚える | `store/tabStore.ts` (`getClosedTabs` / `reopenClosedTab`) / `TabBar.tsx` / `useTabKeyboard.ts` |
| 画面の履歴 (#107) | 切り替えたタブの順を覚え、**Ctrl+Alt+← / →** かタブバー左端のボタンで、前に見ていたタブへ戻る / 進む。閉じたタブは飛ばす。戻ったあとに別のタブへ移ると、進む先は消える。Alt+← は画面デザイナで部品を動かすのに使うので、Ctrl も押す | `tabStore.ts` (`goBackTab` / `goForwardTab`) |
| パンくず (#108) | タブバーの下に 1 行、「区分 › 一覧 › 開いている設計」。一覧の部分を押すと、一覧のタブへ移る。ダッシュボード・ワークスペースは出さない。高さ (22px) は `--tabbar-h` に足し、入力専用モード (Ctrl+Alt+F) では隠す | `utils/breadcrumb.ts` / `shell/PageBreadcrumb.tsx` / `AppShell.tsx` |
| 同じ設計は既存のタブへ (#109) | **新しいタブを作らず既存のタブへ移ることは、もとから `openTab` の仕組みだった** (タブの id が `種類:ID`)。今回は、そのとき既存のタブが一瞬光って知らせるようにした | `tabStore.getTabFlash` / `TabBar.tsx` |

## 2. 一覧 (#101〜#105・#110〜#112・#118〜#120)

| 項目 | 内容 | 実装 |
|---|---|---|
| 保存した絞り込み (#101) | 検索語・種類などの絞り込み・並びに名前を付けて保存し、チップ 1 回で呼び出す (もう一度押すと外れる)。ワークスペースと一覧ごと、最大 12 件。一覧を離れても残る | `utils/listViews.ts` / `ListViewBar.tsx` |
| 絞り込みのチップ (#105) | 「語: 顧客」「種別: バッチ」のチップを並べ、× で 1 つずつ外す。保存した絞り込みと同じ帯に出す。絞っていなくて保存も無いときは出さない | `ListViewBar.tsx` |
| グループ表示 (#102) | 「カテゴリでまとめる」「成熟度でまとめる」で、同じ値の行を見出しの下にまとめる。見出しで畳める (件数つき)。選びは一覧ごとに覚える。まとめている間は、行のドラッグ並べ替えを止める。**対象はテーブル・画面・処理フロー・ビュー定義・ガジェット・帳票** (まとめる値がある一覧)。カード表示では、見出しを 1 行で挟む | `utils/listGroup.ts` / `useListGrouping.ts` / `useListSort` の第 3 引数 / `DataList.tsx` |
| のぞき見 (#103・#112) | 行を選んで **Space** で右にカードを出し (表の全部の列。隠している列も)、↑↓ で行を変えると中身も変わる。**Esc** か Space で閉じる (選択は解除しない)。**Alt を押しながら行にポインタを合わせる**と、ポインタの近くに出る。読み取り専用 | `ListPeek.tsx` / `DataList.tsx` |
| 列幅の記憶 (#104) | **第 3 弾 (#47) で実装済み** (見出しの右端をドラッグ、ダブルクリックで自動に戻る、画面ごとに覚える)。提案書の「現状」の記述が誤りだった。今回は変更なし | `DataList.tsx` (`prefsKey`) |
| まとめての操作 (#110) | 2 件以上を選ぶと、一覧の下に「N 件を選択中」の帯。**お気に入りに追加 / 外す**、**マーカーを付ける** (種類・内容を決めて、選んだ設計すべてに。マーカーを持てる設計だけが対象で、件数を出す)。**成熟度などの設計の中身は、ここでは変えない** (編集画面で、ロックと保存を通して変える) | `SelectionActionBar.tsx` |
| 最近開いた順・編集中 (#111) | 一覧の列の設定のそばの時計のボタンで「最近開いた順」(このブラウザで開いた順)。種類によっては「編集中」(未保存の下書きがある設計だけ) の絞り込みも、チップ・保存した絞り込みに載る。**「自分が最後に編集」は、最終編集者が原本に無いため対象外** | `utils/openedHistory.ts` / `useOpenedSortAccessor.ts` / `useEditingOnly.ts` |
| 行の印 (#118) | 名前が他の設計と重なる・ID が規約の形式 (英小文字・数字・ハイフン) でない行の「No」に警告の印。ホバーで理由。一覧の全件で数える。**プロジェクトごとの命名規約 (設計の分析) の判定は含めない** | `utils/rowMarks.ts` |
| 書き出し (#119) | 「表としてコピー」のメニューに「CSV ファイルで保存」「Excel ファイル (.xlsx) で保存」。画面に出ている列だけ。選んだ行があればその行だけ。CSV は BOM つき (Excel で文字化けしない)。**`= + - @` で始まる文字は ' を付けて文字として開かせる** (取り込んだ名前が式にならないように) | `tableExport.toCsv` / `DataList.tsx` |
| 空状態 (#120) | 検索で 0 件のとき、近い名前 (打ち間違い・一部だけ合う) を最大 3 つのボタンで出し、押すと検索語になる。条件を外すボタンは、もとから | `utils/nearNames.ts` / `EmptyState.tsx` |

## 3. Ctrl+K・ダッシュボード・関わるもの (#113〜#117)

| 項目 | 内容 | 実装 |
|---|---|---|
| 関わるもの (#113) | 参照元のダイアログ (使われている先) の下に「**この設計が使っているもの**」(画面・処理フロー・テーブルが対象。業務フロー・帳票・独自部品・メッセージ・汎用定義などへの参照を、種類とつながりつきで)。クリックで開く。**シーケンス・ビュー・ページレイアウトは、設計どうしのつながり (shared の `buildDesignGraph`) に含まれないため対象外** | `utils/relatedDesigns.ts` / `ReferencesButton.tsx` |
| 検索結果の抜粋 (#114) | 本文の一致 (説明・カラムなど) の抜粋で、検索語に合う部分を目立たせる (全角半角・ひらがな / カタカナの差を無視)。**抜粋から該当の欄へ直接飛ぶことは、検索結果が欄の経路を持たないため未対応** (設計を開く) | `quickOpen.highlightSegments` |
| 種類の接頭辞 (#115) | `t:注文` = テーブルだけ。`s:` 画面 / `i:` 画面項目 / `f:` 処理フロー / `b:` 業務フロー / `r:` 帳票 / `q:` シーケンス / `v:` ビュー・ビュー定義 / `p:` ページレイアウト / `g:` ガジェット / `d:` 汎用定義。表に無い 1 文字 (`x:`) はふつうの検索語。**空欄のときの最近開いた順・お気に入り先頭は、もとからある** | `quickOpen.parseKindPrefix` / `QuickOpen.tsx` |
| 今日やること (#116) | ダッシュボードの新しいパネル。未保存の下書き → 要確認のエラー → 未解決のマーカー (古い順) → 要確認の警告 の順に 1 本の列にし、「1 つ目を開く」「次へ」で 1 つずつ直す | `utils/todayTasks.ts` / `panels/TodayPanel.tsx` |
| パネルの隠し方 (#117) | **パネルの移動・大きさの変更は、もとからある** (ドラッグ / Alt+矢印)。今回は、パネル見出しの「隠す」、「表示するパネル」のメニュー、「初期の配置に戻す」を足した | `DashboardView.tsx` |
