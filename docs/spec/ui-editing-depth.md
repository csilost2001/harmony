# 編集体験の深掘り — 仕様書 (UI 改善提案 続編 第 8 弾)

**Status**: 実装済 (2026-10、ISSUE #1520)
**関連**: [ui-input-reliability.md](ui-input-reliability.md) / [ui-keyboard.md](ui-keyboard.md) / [screen-layout.md](screen-layout.md) / [ux-operations.md](ux-operations.md)

画面デザイナ・処理フロー・テーブル・画面項目の編集に、確かめる・探す・やり直す道具を足した。**原本は書き換えない** (覚えるものは、このブラウザの中だけ。スキーマは変えない)。

## 1. 画面デザイナ (#141〜#144)

| 項目 | 内容 | 実装 |
|---|---|---|
| サンプル値 (#141) | 紙面のツールバーで、入力欄・表に流し込む値を「ダミー / 実らしい値 / なし」から選ぶ。保存はしない (見た目だけ) | `utils/sampleValues.ts` / `LayoutCanvas.tsx` |
| 状態の切替 (#142) | 通常 / 空 / 読み込み中 / エラー を切り替えて見る。選んだ状態の覚えは持たない (開き直せば通常) | 同上 |
| 寸法の表示 (#143) | 「寸法」で、部品の大きさと部品どうしの間隔を数値で重ねる。画面は流れ配置の木なので、吸い付くガイド線は無い | `screen-layout/layoutMeasure.ts` |
| 部品の検索・最近使った部品 (#144) | パレットの検索窓 (名前・種類・かな) と「最近使った」 | `utils/recentParts.ts` / `LayoutPalette.tsx` |

## 2. 処理フロー (#145〜#151)

| 項目 | 内容 | 実装 |
|---|---|---|
| 工程のまとめて畳む・開く (#145) | 目次の「すべて畳む / すべて開く / 要確認だけ」 | `store/stepExpand.ts` / `StepOutlinePanel.tsx` |
| 変数を選ぶと使っている工程を強調 (#146) | 目次の「変数」から選ぶ。定義と使用を区別 | `utils/stepVariables.ts` |
| 工程を囲む (#147) | 選んだ工程を「トランザクション」「繰り返し」で囲む (右クリック)。複数選択・移動・複製は、もとからある | `utils/stepTree.ts` `wrapSteps` |
| 判定表 (#149) | 「図で見る」の「判定表」。分岐の腕を表にし、条件の抜け・重複を示す。条件の組み合わせの全展開ではない | `utils/decisionTable.ts` |
| 条件式の試し実行 (#150) | 「図で見る」の「式を試す」。変数に値を入れて評価する。安全な部分集合の手書きの評価器 (eval 不使用) | `utils/expressionEval.ts` |
| 机上演習 (#151) | 「図で見る」の「机上演習」。分岐を利用者が選んで流れをたどる (評価はしない) | `utils/walkthrough.ts` |

**もとからあった**: #148 工程のひな型の登録は、スニペット (第 4 弾) で足りている。

## 3. テーブル・画面項目 (#152〜#156)

| 項目 | 内容 | 実装 |
|---|---|---|
| 型変更の影響 (#152) | カラムの型・桁を変えると、使っている画面項目・処理フローを警告 | `utils/columnImpact.ts` / `table/ColumnImpactNotice.tsx` |
| サンプルの INSERT (#153) | DDL プレビューの「サンプル行」。型に合う値の INSERT 文を作る (定義には保存しない) | `utils/sampleInserts.ts` |
| インデックスの提案 (#154) | 外部キー・処理フローの検索条件から、足りないインデックスを提案して採用 | `utils/indexSuggestion.ts` |
| 画面項目の区画 (#155) | 区画で絞り込み・「画面の並びに合わせる」。畳める見出しは持たない | `utils/itemSections.ts` |
| 参照先との食い違い (#156) | 項目の型・桁と参照先カラムの食い違いを一覧し、項目側を直す | `utils/itemColumnMismatch.ts` / `ItemColumnMismatchPanel.tsx` |

## 4. 編集の足取り (#157〜#160)

| 項目 | 内容 | 実装 |
|---|---|---|
| スクロール位置の復元 (#157) | 画面を開き直すと、前回のスクロール位置から始まる。**スクロールだけ** (選択・開閉は対象外)。利用者が動かしたときだけ覚え、sessionStorage に置く。直接のリンク (`?` `#`) で来たときは戻さない | `utils/scrollMemory.ts` / `shell/ScrollMemory.tsx` |
| 最後に編集した場所へ (#158) | **Ctrl+Alt+Backspace**。入力した工程・項目・カラム・部品の場所を最大数件覚え、続けて押すとさらに前へ。別のタブの場所へも移る | `store/lastEdit.ts` / `shell/DeepLinkControl.tsx` |
| クリップボード履歴 (#159) | 工程・画面項目・カラムのコピー / 切り取りを直近 10 件覚え、「履歴」(または **Ctrl+Shift+V**) から選び直す。メモリのみ。同じ内容は重ねない | `hooks/useListClipboard.ts` / `common/ClipboardHistoryMenu.tsx` |
| 用語の書き方のゆれ (#160) | テーブルのカラムの表示名で、カタカナの長音 (ユーザ / ユーザー) のゆれを欄の下に示し、「そろえる」。ほかで同じ書き方がすでに使われていれば示さない。「このまま」はその画面を開いている間だけ覚える。**カラムの表示名のみ** | `utils/termVariants.ts` / `common/TermVariantHint.tsx` |
