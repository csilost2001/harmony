# 処理フロー: アウトライン (テキスト) 編集 (試作)

処理フローの工程を、1 行 1 工程のテキストで書く表示。カード・図・表と同じ並びの 4 つめ (「アウトライン」) で、保存形式は今の JSON のまま。スキーマは変えない。

## 書式

```
[入力チェック] 入力値を検証する ^step-01
[DBアクセス] カートを取得する ^step-02
[共通処理] 在庫を引き当てる
```

- `[種類]` は工程の種類の表示名 (入力チェック / DBアクセス / 共通処理 …) か、種類の英名 (`dbAccess`)。
- 行末の `^step-01` は既存の工程との対応づけ (工程の目印)。**無い行は新しい工程**になる。
- 説明の中の改行は `\n`、バックスラッシュは `\\`。
- 空行は無視する。行頭に空白がある行・`[種類]` が無い行・知らない種類は、行番号つきで知らせ、反映は止まる。

## 操作

| 操作 | 結果 |
|---|---|
| 行頭で `/` | 種類を選ぶメニュー (挿入メニューと同じ)。Enter で `[種類] ` を入れる |
| 説明を書き換える | その工程の説明だけが変わる (テーブル・条件・分岐の中身など、ほかの項目は残る) |
| 行を入れ替える | 工程の順序が変わる |
| 行を消す | 工程が消える (「反映」で件数を確かめる。元に戻す操作で戻せる) |
| `^id` の無い行を足す | 種類ごとの既定値で新しい工程ができる |
| `^id` ごと行をコピー | 2 行目は新しい工程になる (元の工程は複製されない) |
| 欄を出る (フォーカスが外れる) | 問題がなく、削除を含まなければ自動で反映。それ以外は「反映」ボタン |
| Esc | 欄から出る |

既存の工程の種類は、テキストから変えられない (種類を書き換えた行は無視して知らせる)。

## できないこと (試作の範囲)

- **入れ子 (インデント)**: 工程の入れ子の置き場がスキーマに無いため (`subSteps` は v3 に無い。[process-flow-keyboard.md](process-flow-keyboard.md))。分岐・繰り返しなどの中身は、カード表示で編集する (アウトラインでは親の工程の行だけが出て、中身は変えずに残る)。
- 種類・テーブル・条件など、説明以外の詳細の編集 (カード表示で行う)。
- 行ごとの補完 (参照先のテーブル名など)。
