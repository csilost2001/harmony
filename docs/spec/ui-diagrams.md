# 図・可視化 — 仕様書 (UI 改善提案 続編 第 7 弾)

**Status**: 実装済 (2026-10、ISSUE #1518)
**関連**: [ui-direct-manipulation.md](ui-direct-manipulation.md) (図の拡大縮小・ER のカラムから線) / [design-analysis.md](design-analysis.md) / [ui-keyboard.md](ui-keyboard.md)

ER 図・画面フローの図に、検索・強調・絞り込み・整列・書き出しの「図の道具」を足し、設計全体のつながり図、処理フローの流れ図とシーケンス図、業務フローの書き出しを足した。**原本は書き換えない** (座標の保存は、これまでと同じ編集中の操作だけ)。スキーマは変えない。覚えるもの (線の形・隠す線の種類・ER のカラム表示・畳んだグループ・基準・表示位置) は、ワークスペースごとにこのブラウザへ置く。

## 1. 図の道具 (ER 図・画面フロー・つながり図)

図の右上のボタン列。実装: `components/common/DiagramTools.tsx` (操作) / `hooks/useDiagramView.ts` + `utils/diagramView.ts` (見え方。React Flow のノード・線を飾る純関数) / `utils/diagramGeom.ts` (座標の計算)。

| 項目 | 内容 |
|---|---|
| 検索 (#122) | **Ctrl+F** (図が見えているとき) か、虫眼鏡。名前・ID・カテゴリの一部で探し、一致を強調してほかを薄くし、先頭へ寄る。Enter / Shift+Enter で次 / 前へ。全角半角・大文字小文字・かなの違いは無視 |
| つながりの強調 (#123) | 選んだノードと、つながるもの (1 段 / 2 段) を濃くし、ほかを薄くする |
| 整列・等間隔 (#121) | 編集中、2 つ以上のノードを選んで、左・中央・右・上・中央・下をそろえる。3 つ以上で横 / 縦に等間隔。グループの中と外の混在は不可。Ctrl+Z で戻せる。**ドラッグ中は、ほかのノードの端・中央にそろうとガイド線が出て、離すと吸い付く** (Shift を押している間は吸い付かない。同じグループの中のノードどうしだけ見る) |
| 関連 N 段だけ表示 (#124) | 選んだノードから 1〜3 段までを表示し、ほかを隠す。「全体を表示に戻す」。ER 図・画面フロー・つながり図で使える (ER に限らず共通) |
| ER のカラム表示 (#125) | 主キー・外部キー + 他のカラムの数 (既定) / すべて / 主キー・外部キーだけ / テーブル名だけ |
| 線の形 (#130) | 曲線 / 角を丸めた直角 / 直角 / 直線。線の経路の再計算は含まない (React Flow の標準の形を選ぶ) |
| 線の種類・グループの畳み (#131・#140) | 線の種類 (ER: 物理 / 論理、画面フロー: 遷移のきっかけごと) の表示・非表示。画面フローのグループを畳む (中の画面と、それにつながる線を隠す。**線をグループへ束ねる表示ではなく、隠すだけ**) |
| 凡例 (#129) | 線・記号・ノードの意味 (図ごと) |
| キーボード (#139) | 選んでいるノードで **]** = つながっている次のノードへ (続けて押すと回る)、**[** = 前に戻る。ノードに読み上げ用の名前。Tab / Enter / 矢印は、もとからある |
| 基準との差分 (#137) | 「いまの状態を基準にする」で覚え (このブラウザだけ)、増えた (緑)・変わった (橙) ノードを色で、消えたものを名前の一覧で出す。**図の中身の指紋 (ER: テーブルの名前・カラム、画面フロー: 名前・URL・種別・グループ) の比較** |
| 表示位置の記憶 (#127) | 図ごとに、最後の表示位置・拡大率を覚え、開き直したとき再現する。図が画面の外に出てしまっているときは、全体を収める。**ER 図は、もとは、データが変わるたびに全体表示へ戻していたが、最初に開いたときだけにした** |

## 2. 書き出し・印刷 (#128・#135・#136)

| 対象 | 内容 |
|---|---|
| ER 図・画面フロー・つながり図 | **画像 (PNG)**: 図の全体 (見えている範囲ではなく、すべてのノード) を、操作の部品を除いて。**Mermaid / PlantUML** の文をコピー (ER・画面フロー)。選んだノードだけの Mermaid をコピー。**印刷**: 用紙 (A4 / A3)・向きを選び、図の全体を 1 ページに収める (ページ分割はしない) |
| 業務フロー | 図の **SVG 保存** (設計書と同じ描画) と Mermaid / PlantUML のコピー |
| 処理フロー | 「図で見る」の **SVG 保存**と Mermaid / PlantUML のコピー (§3) |

**不具合の修正 (もとからあった)**: ER 図の PNG 書き出しは、画面の配色が `color-mix` を使うため、html2canvas が「unsupported color function "color"」で失敗していた (書き出せない)。画像にする前に、`color(srgb …)` を rgba に書き換える (`utils/cssColor.ts`) ことで直した。あわせて、表示している範囲だけでなく図の全体を画像にする。

**できないこと**: ER 図・画面フローの **SVG 書き出し** (ノードが HTML のため。PNG か Mermaid を使う)。**ほかの図へ貼る (複数ノードのコピーと貼り付け)** は対応していない (#136 は、選んだ範囲の Mermaid コピーだけ)。

## 3. つながり図・処理フローの図 (#132・#133・#134)

| 項目 | 内容 | 実装 |
|---|---|---|
| つながり図 (#132) | 設計の分析の新しいタブ「つながり図」。shared の `buildDesignGraph` (画面・処理フロー・テーブル・業務フロー・帳票・独自部品・メッセージ・汎用定義など) を、頼っている側 (左) → 頼られている側 (右) の階層配置で。種類で絞る (数の多い独自部品・メッセージ・正規表現・上限値・汎用定義は、既定で隠す)・図の道具・ダブルクリックでその設計を開く。**シーケンス・ビュー・ページレイアウトは、つながりに含まれないため載らない** | `analysis/tabs/GraphTab.tsx` / `utils/designGraphView.ts` |
| 流れ図 (#133) | 処理フローのエディタの「図で見る」。いまの処理 (アクション) を、読み取り専用で、設計書と同じ描画 (`layoutFlow` / `diagramToSvg`) の流れ図に。編集中の内容がそのまま映る。拡大縮小・SVG 保存・Mermaid / PlantUML のコピー | `process-flow/internal/FlowDiagramDialog.tsx` |
| シーケンス図 (#134) | 同じダイアログの「シーケンス図」タブ。呼び出し元・処理・DB・外部システム・共通処理のやりとりを、工程の順に、Mermaid / PlantUML の文にする (分岐は alt / else、繰り返しは loop、トランザクションは注記)。**描画はしない (貼り付け先で描かれる)。下書き**。Harmony の「シーケンス」は DB の採番の定義で、シーケンス図の機能は、もとから無かった | `shared/diagrams.ts` の `processFlowSequenceText` |
| 画面フローの自動配置 (#126) | 画面フローの編集中のボタン。遷移の向きに沿って左から右へ階層配置する。グループは枠ごとに並べ (グループ内の遷移は、枠のあいだのつながりとして数える)、グループの中の画面は、枠の中で並べる。**画面は縮めない**。入りきらないときは、まず画面どうしのすき間を詰め、それでも入らなければ、**グループの枠を広げる** (広げた大きさは保存される)。サンプル (examples/retail) の画面フローで、重ならず枠に収まることを試験している。取り消せる | `utils/diagramGeom.ts` の `layoutWithGroups` |
