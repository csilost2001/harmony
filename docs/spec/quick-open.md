# クイックオープン (Ctrl+K) — 仕様書

**Status**: 実装済 (2026-10)
**関連**: [list-common.md](list-common.md) / [design-document.md](design-document.md)

## 1. 目的

画面・テーブル・処理フローなどが増えても、一覧を辿らずに目的の設計書へ飛べるようにする。開発者が日々いちばん繰り返す「あれを開く」を 1 つの検索ボックスに集約する。

## 2. 操作

| 操作 | 内容 |
|---|---|
| `Ctrl+K` (Mac は `⌘K`) またはヘッダーの虫眼鏡 | 開く。入力欄にフォーカスがあっても開く。もう一度押すと閉じる |
| 文字を入力 | ID・名前・物理名・画面の URL で絞り込む。空白で区切った語はすべて合うものだけ残る (例: `注文 テーブル`) |
| `↑` `↓` / マウス | 候補を選ぶ |
| `Enter` / クリック | 開く (ふつうのタブとして開く) |
| `Esc` / 外側クリック | 閉じる |

## 3. 検索の対象

画面 (デザイナ) / 画面項目 (項目定義) / テーブル / 処理フロー / 業務フロー / 帳票 / シーケンス / ビュー / ビュー定義 / ページ (ヘッダーメニューにある一覧・設定の画面)。候補は**開くたびに読み直す** (他で追加・改名したものも出る)。ガジェット用の画面は含めない。

## 4. 並び順

1. ID の完全一致 → 前方一致 → 語の先頭 → 途中の一致、の順に点を付ける。名前の一致は ID 等より少し高く扱う
2. 種類名 (「テーブル」「帳票」など) も絞り込みに使える (点は低い)
3. 3 文字以上の語は、文字が順に含まれていれば弱く一致する (`ordcnf` → `order-confirm`)
4. 全角・半角、英大文字・小文字、ひらがな・カタカナの違いは無視する (漢字の読みは扱わない)
5. 同点は登録順

検索は画面に依存しない純関数 (`frontend/src/utils/quickOpen.ts`)。
