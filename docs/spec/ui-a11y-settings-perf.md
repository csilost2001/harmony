誰でも使え (キーボード・スクリーンリーダー・高コントラスト・タッチ)、迷わず (ヘルプ・案内)、重くならない (長い一覧・読み込み・長い処理) ための共通の土台。**原本 (設計の JSON) は書き換えない。スキーマは変えない**。覚えるもの (動きの設定・キーの割り当て・通しの案内の進み具合・新しくなったことの既読) は、このブラウザにだけ置く。

## 1. キーボード・スクリーンリーダー

| 項目 | 内容 | 実装 |
|---|---|---|
| スキップリンク (#181) | Tab の最初のフォーカスで、「本文へ移動」「タブへ移動」「ヘッダーへ移動」が現れる。Enter で、その領域へフォーカスが移る。マウスでは、フォーカスされるまで見えない | `components/shell/SkipLinks.tsx` |
| フォーカスリング (#182) | キーボードのフォーカスの輪郭を、トークン `--hm-focus-ring` (ライト・ダークで別の値) 1 か所で決める。`:where` で詳細度 0 にするので、部品ごとの指定が優先される。**部品ごとに `outline: none` を書く宣言は増やさない**: `npm run check` の「フォーカス輪郭の検査」(`scripts/verify/no-new-outline-none.mjs`。既存の 37 件は baseline に控え、ファイルごとに増えたら失敗) | `styles/a11y.css` / `tokens.css` |
| 高コントラスト・強制カラー (#183) | OS の「コントラストを上げる」(`prefers-contrast: more`) に、アプリの「コントラスト: 高」と同じ値で従う。Windows の強制カラー (`forced-colors: active`) では、枠・フォーカス・選択・ダイアログを、システムの色で保つ (背景色だけで表していた境界に、枠を付ける) | `styles/a11y.css` |
| 動きを減らす (#184) | OS の設定 (既定) か、表示の設定の「動き」で「減らす / 減らさない」を選ぶ。「減らさない」を選ぶと、個別の CSS に書いた `prefers-reduced-motion` の規則も、打ち消す。減らすと、CSS のアニメーション・遷移を止め (読み込み中の回転は、止めずにゆっくりにする)、図のズーム・移動の補間 (`motionMs`) も 0 にする | `theme/motionPrefs.ts` / `styles/motion.css` |
| 表の読み上げ (#185) | 一覧の表 (`DataList`) に `role="grid"`・行数 (`aria-rowcount`)・行の位置 (`aria-rowindex`)・選択 (`aria-selected`)・並び替えの向き (`aria-sort`)・表の名前を付ける。**セル単位のキー操作 (矢印でセルを移る) は、grid の約束どおりには、していない** (行単位の操作のまま) | `components/common/DataList.tsx` |
| ランドマークと見出し (#186) | **ランドマーク (banner / navigation / main)・見出しの段の検査は、もとからあった** (`e2e/a11y-structure.spec.ts`)。今回は、画面ごとに h1 が 1 つになるよう、h1 を持たない画面に、タブの名前の見えない h1 を補う (画面が持つときは隠す。エディタのヘッダーの `role="heading" aria-level="1"` も画面の見出し)。検査に「h1 が 1 つ」を足した。一部のエディタの見出しは `aria-level` で段をそろえた | `components/shell/PageHeading.tsx` |
| 状態の知らせ (#187) | 通知 (トースト) は、もとから `role="status"`。トーストにならない変化 (タブの切り替え・一覧の件数の変化) を、見えない読み上げ領域へ流す。続けた知らせは、0.7 秒にまとめ、新しい 3 件までを 1 回で読む | `utils/announce.ts` / `components/common/LiveAnnouncer.tsx` |
| ツールチップ (#196) | **キーボードのフォーカスで**、要素の title を、画面に出す (350 ms 後。末尾の「(Ctrl+S)」のようなキーは kbd で。Esc で消える)。マウスでは、これまでどおり、ブラウザ標準の title の表示 (二重に出さない)。title の文は要素に残す (読み上げ・既存の操作は、そのまま)。**title を共通の部品に置き換えてはいない** | `components/common/FocusTooltips.tsx` / `utils/tooltipText.ts` |
| メニューのキー併記 (#197) | 台帳 (`utils/menuShortcuts.ts`) のキーは、ショートカット一覧に載っているものだけ (試験が見張る)。タブの右クリックメニューに、閉じる・左右へ動かすのキーを併記。一覧の右クリックメニューの標準の操作 (コピー・貼り付け・削除など) は、もとから併記済みで、台帳と食い違わないことを試験で見張る。ヘッダーメニュー (ページの移動) には、対応するショートカットが無い (Ctrl+K で探す) | `utils/menuShortcuts.ts` |
| タッチ・タブレット (#198) | 指で触る環境 (`pointer: coarse`) では、見た目の大きさは保ったまま触れる範囲を広げ (ヘッダー・タブ)、ボタン・入力欄・一覧の行を 40px 以上にする。図の**ピンチ拡大は、React Flow の標準**。**タッチでの範囲選択は未対応** (行の長押しは、第 3 弾から) | `styles/a11y.css` |

## 2. 設定・ヘルプ・学習

| 項目 | 内容 | 実装 |
|---|---|---|
| ショートカットの割り当て (#188) | ショートカット一覧の「キーの割り当てを変える」で、変えられるショートカットの「変える」を押し、次に押したキーが割り当てになる (Esc でやめる)。**変えられるのは、台帳の 6 件** (最後に編集した場所へ・リンクのコピー・入力専用モード・設計全体の検索置換・コピーの履歴・マーカーの追加)。**編集の基本のキー (保存・元に戻す・コピーなど)・タブ・コマンドパレット・ブラウザが使うキーは、固定で、割り当てられない** (衝突は理由を出して断る。**固定のキーは、ショートカット一覧の「変えられない項目」から導く**ので、一覧に足したキーは、自動で固定になる。Shift だけの組み合わせ・修飾キーなしも断る)。設定の書き出しで持ち出せる | `utils/shortcutBindings.ts` |
| ヘルプの検索と文脈ヘルプ (#189) | ショートカット一覧 (`?`) の上に、検索欄。項目ごとのヘルプとショートカットを、全角半角・大文字小文字・かなの種類を無視して探す (空白区切りは、すべてを含む。題名の一致が先)。検索語が空のときは、「この画面の項目のヘルプ」を先頭に出す。**検索の対象は、アプリの中にあるヘルプ (項目ごとのヘルプとショートカット) で、docs/ の仕様書の全文ではない** | `utils/helpSearch.ts` |
| 新しくなったこと (#190) | **更新の案内 (トースト) は、もとからあった**。今回は、更新のあと最初に、前に見たリリースノートより新しいものを、5 件までのダイアログで出す (閉じれば、同じものは出ない。初回は出さない) | `components/operations/WhatsNewDialog.tsx` / `utils/updateNotice.ts` |
| 設定の書き出し・読み込み (#191) | 表示の設定の「設定の書き出し・読み込み…」(コマンドパレットにも)。表示・通知・利用者名・ショートカット・お気に入り・スニペット・一覧の設定・個人メモと試作を、1 つの JSON にする。**接続トークン・開いているタブ・下書き・見た版は含めない**。読み込みは、種類を選んで確認してから (台帳に無い項目・大きすぎる値は除く)。ワークスペースごとの設定は、ワークスペースの ID が同じものにだけ効く。読み込んだあとは、画面を読み込み直して反映する | `utils/settingsBackup.ts` |
| 通しの案内 (#199) | **ツアー (画面ごとの案内) と「はじめかた」(何から作るか) は、もとからあった**。今回は、受注を題材に、テーブル → 画面 → 画面項目 → 処理フロー → 点検 → 設計書の 6 手順を 1 周する案内 (「はじめかた」・コマンドパレットから)。各手順に、開く画面・入れる値の例 (カラムの例は、実際の「表から貼り付け」で読めることを試験で確認)・確かめ方がある。終えた手順は、ワークスペースごとに覚える。**手順の完了は、自動では判定しない (手で印を付ける)** | `utils/guidedWalkthrough.ts` |
| エラー報告用のコピー (#200) | **エラーの詳細の「状況をまとめてコピー」(JSON) は、もとからあった**。今回は、版・コミット・URL (token などは伏せる)・開いていた画面・直前の操作 5 件・エラー・未保存の下書きを、ISSUE やチャットに貼れる文にする「報告用の文をコピー」を足した (設計の中身・サーバのログは含めない) | `utils/errorReport.ts` |

## 3. 性能・待ち

| 項目 | 内容 | 実装 |
|---|---|---|
| 長い一覧の窓表示 (#192) | 150 行以上の一覧の表 (`DataList` の表表示。グループ表示でないとき) は、見える範囲 (と前後 20 行) だけを描き、残りの高さは、上下の余白の行で補う。行の高さは、描いた行から測る。**画面内の検索 (Ctrl+F) を開いている間は、窓表示を止める** (すべての行を探せるように)。**カード表示・グループ表示・DataList 以外 (目次・検索結果) は対象外** | `utils/windowing.ts` |
| 読み込み中の骨組み (#193) | 読み込み中の表示 (`LoadingBlock`) に、200 ms を過ぎたら、骨組み (うっすらした帯) を足す。一瞬で終わるものには、出さない。動きを減らす設定では、帯の揺らぎは止まる。**一覧・エディタごとの個別の骨組みは、していない** | `components/common/LoadingBlock.tsx` |
| 長い処理の進み具合 (#194) | 件数のある処理を、1 件ずつ実行して、「7 / 10 件」と帯・中止ボタンを出す共通の部品。**DDL の取り込み・OpenAPI の取り込みに適用**。中止しても、処理済みの件は元に戻さない (「10 件中 7 件を取り込みました (中止。処理済みの 7 件は残っています)」)。**失敗・中止があったときは、入力を残し**、失敗した名前を知らせる (取り込めたものは「作りません」になるので、そのまま、もう一度取り込める)。**一括置換・書き出しは、1 回の呼び出しなので、対象外** | `utils/batchTask.ts` / `components/common/ProgressBar.tsx` |
| 接続が切れたあとの復帰 (#195) | 切れている間の表示に「切れている間は?」(できること・できないこと・未保存の下書きの数) を足し、復旧のお知らせに、未保存の下書きがあることを足した。**もとからの不具合も直した**: 一度復旧したあと、もう一度切れても、知らせが出なかった | `components/common/ConnectionStatus.tsx` |

## 4. できないこと・範囲を絞った点

- 表のセル単位のキー操作 (grid の矢印操作)・タッチでの範囲選択 (#185・#198)
- 共通のツールチップへの title の置き換え (#196)。メニューへのキー併記は、タブの右クリックメニューだけ追加 (#197)
- ショートカットの割り当ては 6 件だけ (#188)。ヘルプの検索は、アプリの中のヘルプだけ (#189)
- 窓表示は、一覧の表表示だけ (#192)。骨組みは、共通の読み込み中の表示だけ (#193)。進み具合は、2 つの取り込みだけ (#194)
